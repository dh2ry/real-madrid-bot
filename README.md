# بوت ريال مدريد ⚪

يشتغل تلقائياً على GitHub Actions كل 10 دقائق، وينشر في حسابك على X:

| المحتوى | متى |
|---|---|
| 📰 أهم الأخبار مترجمة ومختصرة: مواقع إخبارية + الموقع الرسمي لريال مدريد + حسابات X | كل 30 دقيقة (فقط لو فيه خبر مهم) |
| 📋 بطاقة التشكيلة الرسمية مصممة | أول ما تُعلن (عادة قبل المباراة بساعة) |
| 🎙️ المؤتمر الصحفي قبل المباراة — المدربين | اليوم اللي قبل المباراة |
| 🎙️ المؤتمر الصحفي بعد المباراة — المدربين | بعد نهاية المباراة |
| 🔴 أحداث المباراة مباشرة: البداية، الأهداف، البطاقات، التبديلات، الإصابات، الاستراحة، إلغاء هدف بالفار، والنهاية مع بطاقة نتيجة مصممة | يفحص كل دقيقة من قبل المباراة بربع ساعة لين النهاية |

المؤتمرات تُنشر كسلسلة تغريدات: عنوان + أبرز التصريحات مترجمة بين « ».
لو حسابك موثّق (Premium) وتبيها منشور واحد طويل، خلّ `"longPosts": true` في `config.json`.

## المفاتيح المطلوبة

| السر في GitHub | من وين | ضروري؟ |
|---|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com | ✅ |
| `X_API_KEY` `X_API_SECRET` `X_ACCESS_TOKEN` `X_ACCESS_SECRET` | developer.x.com | ✅ |
| `FOOTBALL_DATA_KEY` | football-data.org/client/register (مجاني) | ✅ جدول المباريات |
| `APIFOOTBALL_KEY` | dashboard.api-football.com (مجاني) | اختياري |

**مفاتيح X:** أنشئ App، ومن User authentication settings خلّ الصلاحية **Read and write**، وبعدها ولّد الـ Access Token (لو ولّدته قبل تغيير الصلاحية بيطلع خطأ 403).

**التشكيلة:** البوت يحاول API-Football أولاً، وإذا ما توفرت (الخطة المجانية ممكن ما تغطي الموسم الحالي) يخلي Claude يبحث عن التشكيلة الرسمية المعلنة. ما ينشر أبداً تشكيلة متوقعة.

## التركيب

1. أنشئ Repo جديد في GitHub وارفع كل الملفات (مع مجلدي `.github` و `state`).
   - **أنصحك يكون Public**: البوت يشتغل كل 10 دقائق، والدقائق المجانية في الـ Private ما تكفي. المفاتيح تبقى سرية تماماً في الحالتين.
2. Settings ← Secrets and variables ← Actions ← أضف المفاتيح اللي فوق.
3. عدّل `handle` في `config.json` لاسم حسابك (يظهر على البطاقة).

## التجربة

من تبويب **Actions** ← Real Madrid Bot ← **Run workflow**:
- **preview_card**: يصمم بطاقة تشكيلة تجريبية لمباراتك الجاية. تلقاها في أسفل صفحة التشغيل تحت **Artifacts ← images**.
- **dry_run**: يشغّل كل شي ويطبع التغريدات في السجل بدون نشر.

## الإعدادات (`config.json`)

- `timezone` / `timezoneLabel`: التوقيت المكتوب على البطاقة
- `fontFile`: خط البطاقة (حالياً ثمانية Serif Display في `assets/fonts`). لتغييره حط ملف الخط في نفس المجلد وعدّل المسار
- `crests`: الشعارات تتحمّل تلقائياً من football-data. لو تبي شعار معيّن لنادي، حط ملفه في `assets/crests` واكتب اسم النادي بالإنجليزي ومسار الملف (أو رابط صورة)، مثل:
  ```json
  "crests": { "Real Madrid": "assets/crests/real-madrid.png" }
  ```
- `xSources`: حسابات X اللي يتابعها البوت (بدون @):
  - `rmAccounts`: حسابات خاصة بريال مدريد، ياخذ كل تغريداتهم
  - `generalAccounts`: حسابات عامة، ياخذ بس تغريداتهم اللي فيها ريال مدريد
  - X يحاسب على كل تغريدة يقراها البوت، فكل ما زادت الحسابات زادت التكلفة
- `official`: أخبار الموقع الرسمي realmadrid.com (الفريق الأول)
- `live`: إعدادات الأحداث المباشرة. `substitutions` / `injuries` لتبديلات وإصابات ريال، و `opponentSubstitutions` / `opponentInjuries` للخصم (مطفية افتراضياً)، و `resultCard` لبطاقة النتيجة. مثلاً `"opponentYellowCards": false` يوقف بطاقات الخصم الصفراء، و `"yellowCards": false` يوقف بطاقات ريال الصفراء (المصدر: بيانات ESPN المجانية)
- `pressers.opponent`: خلّها `false` لو ما تبي مؤتمر مدرب الفريق المنافس
- `pressers.maxQuotes`: عدد التصريحات في كل سلسلة
- `lineup.startMinutesBefore`: متى يبدأ يدوّر على التشكيلة
- `extraFixtures`: مباريات كأس الملك والسوبر الإسباني (مو موجودة في الخطة المجانية لـ football-data). مثال:
  ```json
  "extraFixtures": [{ "kickoff": "2026-12-17T20:00:00Z", "opponent": "Athletic Club", "competition": "Copa del Rey", "isHome": false }]
  ```
  (الوقت بتوقيت UTC، يعني توقيت مكة ناقص 3 ساعات)
- `maxTweetsPerRun`, `maxAgeHours`, `style`, `feeds`, `keywords`: إعدادات الأخبار
