# حاسبة الكربوهيدرات والإنسولين 🍽️💉

تطبيق ويب عربي (RTL) يعمل على الآيفون والآيباد والكمبيوتر، ويمكن تثبيته كتطبيق (PWA) ويعمل بدون إنترنت.
اختر أطعمة الوجبة وكمياتها لتحصل فوراً على إجمالي الكربوهيدرات والناتج الحسابي لجرعة الإنسولين.

> ⚠️ **تنبيه طبي:** الحاسبة تعرض ناتج المعادلة `إجمالي الكربوهيدرات ÷ معامل الكربوهيدرات` فقط.
> هذا الناتج ليس وصفة طبية ولا أمراً بإعطاء جرعة. لا يضيف التطبيق جرعات تصحيحية ولا يقرّب الجرعة.
> يجب أن يعتمد الطبيب المعامل، وراجع خطة العلاج المعتمدة قبل أي جرعة.

## الصفحات

| الصفحة | ماذا تفعل |
|---|---|
| 🧮 **الحاسبة** | بحث بالاسم أو تصفح 10 تصنيفات، ثم تحديد الكمية (بالجرام أو الحبة أو الكوب أو القطعة أو الكيس…). تضم «مكونات الوجبة الحالية» مع التعديل والحذف، و«حاسبة جرعة الإنسولين» |
| 📋 **الوجبات** | حفظ الوجبة باسم، وعرض الوجبات المحفوظة مع إجمالي كل منها، وإعادة الاستخدام، والتعديل، وإعادة التسمية، والحذف |
| 🗂️ **إدارة الأطعمة** | إضافة صنف وتعديله وحذفه، وتغيير التصنيف والوحدة والكمية المرجعية والكربوهيدرات، وصورة اختيارية، وبحث، وتصفية للأصناف الناقصة |
| ⚙️ **الإعدادات** | معامل الكربوهيدرات (الافتراضي 25) مع استعادة الافتراضي، وتصدير الأطعمة واستيرادها (JSON / CSV)، ونسخة احتياطية كاملة واستعادتها |

## طريقة الحساب

- **كربوهيدرات الصنف** = الكمية المختارة ÷ الكمية المرجعية × كربوهيدرات المرجع
  - مثال: 100 جرام أرز = 30 جم، فإن 150 جرام = 150 ÷ 100 × 30 = **45 جم**
  - مثال: بسكوت ماري 4 حبات = 15 جم، فإن حبتين = **7.5 جم**
- **القياس المكافئ:** بعض الأصناف لها قياس ثانٍ مذكور في الجدول، مثل `1 كوب (250 مل)` و`2 حبة (32 جرام)` و`10 حبات كبيرة أو 15 صغيرة`. يمكنك إدخال الكمية بأي منهما.
- **جرعة الإنسولين الحسابية** = إجمالي الكربوهيدرات ÷ المعامل، وتُعرض بمنزلتين عشريتين (مثال: 87 ÷ 25 = **3.48**).

## قاعدة البيانات

- الأصناف الأولية موجودة في `data/foods.js`، وهي **122 صنفاً** مستخرجة من صور الجداول الست (IMG_2500 حتى IMG_2505). كل صنف يحمل اسم الصورة والجدول الذي أُخذ منه.
- تُحفظ كل البيانات (الأطعمة والتعديلات والوجبات والإعدادات والوجبة الحالية) في **IndexedDB** على الجهاز، فلا تختفي عند تحديث الصفحة أو إغلاقها.
- البيانات محلية لكل جهاز ومتصفح. لنقلها إلى جهاز آخر استخدم «النسخ الاحتياطي» من الإعدادات.

### أصناف تحتاج مراجعتك

| الصنف | السبب |
|---|---|
| أناناس – توت | خانة الكمية فارغة في الجدول، ويظهر الصنف بعلامة «بيانات ناقصة» حتى تكمله |
| تين مجفف | خانة الكربوهيدرات فارغة في الجدول |
| عصير فواكه (½ كوب) | خانة الكربوهيدرات فارغة في الجدول |
| مشمش مجفف | الجدول يذكر «3–4 حبات»، واستُخدم الحد الأدنى 3 |
| بطاطا عيدان (Stix) | الجدول يقول 30 جم = 32 جم كربوهيدرات (الكربوهيدرات أكبر من الوزن)، فتحقق من العبوة |
| كورن فليكس (بخط اليد) | إضافة مكتوبة بخط اليد أسفل الجدول (كوب = 20 جم)، وكلمة بعد «كوب» غير واضحة |
| أصناف مكتوب فيها «صغير / كبير» فقط | سُجلت بوحدة «حبة» مع ذكر الحجم في الاسم، مثل «تويكس (صغير)» |
| أصناف مكتوب فيها رقم فقط بدون وحدة | سُجلت بوحدة «حبة»، مثل التوست والخبز في مجموعة النشويات |

تصنيف «الخضروات» فارغ حالياً لأن الجداول المرفقة لا تحتوي على خضروات، ويمكنك الإضافة إليه من «إدارة الأطعمة».

لإكمال صنف ناقص: افتح **إدارة الأطعمة** ← فعّل «الناقصة فقط» ← ✏️ تعديل.

## التشغيل محلياً

التطبيق ملفات ثابتة فقط، لا يحتاج خادماً ولا بناء:

```bash
cd carb-calculator
npm start          # python3 -m http.server 8080 ثم افتح http://localhost:8080
npm test           # اختبارات المعادلات وسلامة البيانات
npm run test:e2e   # اختبار الواجهة كاملاً في متصفح (يتطلب تشغيل الخادم و Playwright)
```

للنشر: ارفع محتوى المجلد إلى أي استضافة ملفات ثابتة تعمل عبر HTTPS (مثل GitHub Pages أو Netlify أو Cloudflare Pages). PWA تحتاج HTTPS.

### لإضافة أصناف جديدة للقاعدة الأصلية مستقبلاً

أضفها في `data/foods.js` بمعرّف `seedId` جديد، ثم ارفع `SEED_VERSION` بمقدار واحد، وارفع `VERSION` في `sw.js`.
عند فتح التطبيق تُضاف الأصناف الجديدة فقط، دون المساس بتعديلات المستخدم ودون إعادة الأصناف التي حذفها.
